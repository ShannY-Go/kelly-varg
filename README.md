# Сайт-портфолио персонажа «Келли Варг»

## Состав проекта

В анкете персонажа указано: Келли Варг; фамилия матери — Варг. Фамилию «Эвил» сохранил для отцовского рода, брата и династии, как в исходном тексте.

- `index.html` — сайт, оформление, интерактивные карточки и режим администратора.
- `site-data.json` — весь текст анкеты и биографии, а также загруженные изображения (после экспорта).
- `profile-kelly-varg.md` — текст анкеты из исходного Markdown с приведёнными к «Варг» именами и фамилиями.

## Публикация на GitHub Pages

1. Создай новый репозиторий на GitHub.
2. Загрузи в корень репозитория файлы `index.html` и `site-data.json`. Файл `profile-kelly-varg.md` можно оставить как исходник или не загружать.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/(root)`, затем нажми **Save**.
6. После публикации GitHub Pages покажет адрес сайта.

## Как редактировать сайт

1. Открой опубликованный сайт.
2. Нажми **Shift + E**.
3. Введи пароль администратора: `76717671`.
4. Когда появится панель администратора, нажимай на обведённые текстовые элементы и редактируй их прямо на странице.
5. Кнопка **Загрузить портрет** меняет главное изображение. Кнопка **Добавить изображения** добавляет фотографии в галерею.
6. Нажми **Экспорт для GitHub**. Браузер скачает обновлённый `site-data.json`.
7. Открой репозиторий GitHub, загрузи новый `site-data.json` поверх старого и подтверди commit. После обновления сайта новые тексты и изображения будут доступны всем посетителям.

**Важно:** кнопка «Сохранить черновик» хранит изменения только в текущем браузере. Чтобы обновления увидели остальные, обязательно экспортируй `site-data.json` и загрузи его в репозиторий. Картинки включаются в этот JSON автоматически.

## Локальный запуск

Сайт использует `fetch()` для чтения `site-data.json`, поэтому не открывай `index.html` двойным щелчком через `file://`.

Можно запустить локальный сервер из папки сайта:

```bash
python -m http.server 8000
```

Затем открой `http://localhost:8000`.

## Ограничение пароля

Пароль `76717671` встроен в JavaScript сайта. Это простой переключатель режима редактирования, а не настоящая защита: посетитель, который умеет смотреть исходный код, сможет найти пароль. Не размещай в этом статическом сайте личные секреты и не используй его как защищённую админ-панель. Для настоящей защиты нужен серверный вход или GitHub OAuth с серверной частью.

- Редактирование текста, портрета и галереи.
- Экспорт публикационных данных в `site-data.json`.
